# 雪团猫咪桌面宠物源码

这是雪团桌面宠物的可维护源码与资源备份。

## 内容

- `pet.json`：Codex 宠物配置
- `assets/spritesheet.png`：1536×2288 的 v2 精灵图，8×11 格，每格 192×208
- `scripts/rebuild_atlas.py`：从动作条带重建 atlas 的脚本
- `scripts/boost_cat_contrast.py`：增强白色背景可见性的对比度脚本
- `../xuetuan-share/`：可在浏览器中运行的动态 HTML 页面

## 网页预览

打开仓库中的 `xuetuan-share/index.html`，或访问：

https://wanliqin.github.io/xuetuan-share/

## 说明

脚本中的参考素材路径是本机生成路径。若在另一台电脑重新生成，需要把猫咪参考图放入对应目录后，再按脚本中的路径调整输入位置。
